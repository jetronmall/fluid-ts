# @jetronticket/api

TypeScript client for **Jetron Fluid**, the Jetron Ticket headless API. Ships endpoint functions and type definitions generated from the OpenAPI spec.

> Work in progress.

## Install

```sh
npm install @jetronticket/api
```

## Development

From the repo root:

- `pnpm --filter @jetronticket/api build`
- `pnpm --filter @jetronticket/api dev`
- `pnpm --filter @jetronticket/api typecheck`
